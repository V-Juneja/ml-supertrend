# IQIC Strategy Declaration: rubric self-review

This is an internal estimate against the published 80-point declaration rubric, not an IQIC judge score.

| Criterion | Estimate | Basis |
|---|---:|---|
| Investment thesis and strategy | 17/20 | Clear reversal hypothesis, signal sequence, adaptive settings, sizing, and exit rules. The live competition record will determine whether implementation follows the declaration. |
| Quantitative methodology | 16/20 | Defined variables and equations, documented replay assumptions, trade statistics, parameter checks, and several risk simulations. The long-horizon archived replay and the declared adaptive strategy are different evidence sets. |
| Risk management | 15/20 | Position, sector, theme, planned-loss, liquidity, session-loss, drawdown, gap, volatility, and correlation controls are specified. Simulation uses a short calibration window and does not model signal-driven portfolio returns. |
| Evidence-based decision making | 7/10 | Results include costs, benchmark, sensitivity checks, input sources, and reproducible code. The archived ranking replay is not a direct test of the exact declared ML signal rules. |
| Communication and presentation | 8/10 | Equations name and define variables, charts and tables are sourced, and the data-to-decision path is explicit. Some technical detail remains dense. |
| **Estimated total** | **63/80** | A reasoned self-assessment; judges assign the actual score. |

## Highest-value improvement

Log every competition signal, model setting, order, fill, cost, and exit reason. This would make the declared strategy auditable and provide direct evidence on whether the adaptive model adds value over fixed settings.
